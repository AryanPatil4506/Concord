A worker crashes
Agents keep their task bundles (disconnected autonomy); a standby worker rebuilds state from the event log — nothing is lost because every decision is a record.
The cloud link drops
Edge gateway runs decentralised CBBA locally; agents enforce the battery-reserve rule on board and return home with margin.
LLM outage or cost spike
Zero impact on control — the LLM is not in the loop. Local model + preset mission templates + template explanations.
A bad release
CI replays the 300-seed benchmark on every pull request and blocks merges that regress time-to-aid, losses or churn; canary rollout.
